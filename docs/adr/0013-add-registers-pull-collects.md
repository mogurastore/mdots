# addは登録に専念し取り込みはpullが行う

`mdots add <dest>` は未登録の既存ファイルを新規Entryとして登録するだけとし、ファイルのコピーは行わない。登録後の回収は `pull` が行う。Store発見（カレント直下のみ）→dest正規化（`~/...`またはHOME配下絶対パス→`~/...`）→src算出（`~/`除去＋`dotfiles/`＋残り）→dest存在・ファイル確認→Store側src不在確認→素のsrc形式で登録（overrideは書かない）→保存の順に行い、検証失敗時はmdots.tomlを変更しない。責務を分けて上書き事故と二重実装を避けるため。
